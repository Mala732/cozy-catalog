WHAT AM I LOOKING AT?

ENVIRONMENT STATUS — four live checks, not static labels. Application and API confirm the FastAPI service is up and answering requests; Database reflects a real query (SELECT 1) run against Postgres on every page load, so if the DB container is down this turns red instead of silently showing green; Environment is read from a DEPLOY_ENVIRONMENT variable set at deploy time.

DEPLOYMENT INFO — version, platform and runtime are also environment-driven (DEPLOY_VERSION, DEPLOY_PLATFORM), not hardcoded strings, so the same image reports correctly whether it's run locally or from the Terraform-provisioned Azure VM.

RECENT DEPLOYMENTS — every container start writes a row to a deployments table via a FastAPI startup hook. This panel is reading that table live, so each redeploy actually appends a new entry rather than the list being seeded fake data.

Source: GET /api/status · /api/info · /api/deployments — all three defined in backend/app/main.py.
